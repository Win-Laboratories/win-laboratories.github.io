# win-laboratories.github.io
Archiving and restoring the design and engineering legacy of Win Laboratories and its founder, Dr Sao Win.

**Logo and icons:** the original logo file is `assets/logos/win-laboratories-inc-logo.jpg`, kept as received. The header emblem (`assets/logos/win-laboratories-mark.png`), `favicon.png` and `apple-touch-icon.png` are cropped from it. `favicon.ico` uses the central W, which stays legible at small sizes.

**Site structure:** the sections and sub-pages are listed in `_data/sections.yml`, which drives the navigation, breadcrumbs, section menus and home-page cards. To add a page, add it there and create its `index.md`.
